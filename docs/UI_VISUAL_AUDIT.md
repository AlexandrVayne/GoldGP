# UI VISUAL AUDIT — GoldGP 2.8.3

> Честный визуальный аудит двух скоупов: (1) аддон в игре, (2) веб-превью.
> Метод: чтение UIKit/UI/Welcome/Dialog/Options + метрики grep'ом (палитра,
> шрифты, размеры, дубли). Дата: сессия v2.8.3. Ничего не менялось — только анализ.

## 1. Что УЖЕ хорошо (не трогать)

- **Единая палитра в UIKit** (200 строк): тёмные фоны 0.06–0.28 + золотой акцент
  + классовые цвета. Вне палитры всего 8 `|cff`-литералов, из них 6 — эпик-фиолетовый
  `a335ee` (качество предмета, легитимно). Это редкий уровень дисциплины для WoW-аддона.
- **Flat-стиль с тонкими рамками** (1–2px, WHITE8x8) — сам по себе современный и
  минималистичный, переезжать некуда.
- **Единый `create_button`** — 100% кнопок (кроме 4 исключений, см. P1-1) имеют
  одинаковый hover/down/active-цикл и звук.
- **Геометрия системна:** title 30 / toolbar 40 / header 24 / footer 40 / шаг 2px.
- **Шрифты** — только Blizzard-объекты (GameFontHighlightSmall ×59, Highlight ×46,
  NormalLarge ×25): консистентно и без проблем с кириллицей.

## 4. Целевое направление стиля (токены)

Современный минимализм здесь = **воздух + иерархия + единообразие**, без новых цветов:

1. Шаг сетки 2px сохранить; внутренние отступы панелей унифицировать (8/12/16).
2. Два размера кнопок (24/20) вместо четырёх значений.
3. Один фабричный метод шапки окна → все 4 окна пиксель-в-пиксель.
4. Контраст текста: text_dim 0.55 поднять до 0.60 (читаемость серого на тёмном).
5. Пустые состояния — у каждой области данных (таблица, замены, журнал, фласки).
