# RELEASE PLAN — подготовка GoldGP к публичному релизу

> Пошаговый план чистки: мусор, дубли, комментарии. Выполняется ПОСТЕПЕННО —
> одна фаза = одна сессия, чтобы не перегружать контекст и всегда иметь
> рабочую версию. Текущая точка отсчёта: v2.8.3 (28 файлов, 18 058 строк Lua,
> ~20% строк — комментарии, 874 маркера «v2.x.y» в коде).

## Принципы

1. **После каждой фазы аддон рабочий**: luaparse 19/19 + регресс-чеклист + новая zip.
2. **STOP-лист (не трогаем никогда):** ChatThrottleLib.lua, протоколы V2^/CHUNK/STB_,
   формат officer note «Gold,GP [ОТП]», pending-очередь, Storage/Award-инварианты
   (PROJECT_MEMORY.md §2), логика boot+waiter.
3. **Правило удаления:** что-то удаляем только после grep-доказательства отсутствия
   потребителей; сомнение = переносим в список «решить позже», не удаляем.
4. История правок живёт в CHANGELOG.md, НЕ в коде — это фундамент политики комментариев.
